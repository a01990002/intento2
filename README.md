# Blue Launch - Landing Page Definitiva

Sitio web futurista e inmersivo para la entrega final del proyecto **Blue Launch**.

## 🚀 Publicación en GitHub Pages

1. Crea un repositorio público en GitHub (ej. `blue-launch-landing`).
2. Sube los archivos `index.html`, `style.css`, `script.js` y `README.md` a la rama principal (`main`).
3. Ve a **Settings** > **Pages** en tu repositorio.
4. En **Build and deployment**, selecciona `Deploy from a branch` y escoge la rama `main` (`/root`).
5. Guarda los cambios. ¡Tu sitio estará en línea con animación de cohetes, reloj futurista y efectos de audio!
